# Philippine FIES: Proxy Indicators for Poverty Measurement

An end-to-end data analysis project investigating the Philippine Family Income and Expenditure Survey (FIES) dataset to identify household expenditure variables that can serve as reliable proxy indicators for poverty measurement.

---

##  Project Overview
Poverty measurement traditionally relies on comprehensive income data, which can be complex or delayed to collect. This project analyzes **290,808 records** from the FIES dataset to discover hidden expenditure patterns, correlations, and regional disparities that can help approximate household poverty status using core indicator variables.

---

##  Key Steps & Methodology
* **Data Cleaning & Exploration**: Processed and analyzed **290,808 records** from the FIES dataset to evaluate household income and expenditure variables.
* **Statistical Analysis**: Applied **Pearson correlation analysis** to examine the strength and direction of relationships between household income levels and selected expenditure categories.
* **Pattern Recognition**: Identified distinct expenditure behaviors associated with poverty—specifically focusing on staple consumption, very low-income brackets, and basic utility expenditures across various regions and household types.
* **Data-Driven Recommendations**: Formulated strategic insights incorporating survey-weighted analysis, cross-validation techniques, and regional disparity breakdowns.
* **Data Visualization**: Designed interactive and dynamic dashboards using **Power BI** to communicate analytical outcomes effectively to stakeholders.

---

##  Key Insights
* **Basic Utilities & Staples**: Expenditure shares on basic food staples and utilities show strong negative correlations with overall household income, making them prime candidates for proxy poverty indicators.
* **Regional Disparities**: Expenditure patterns vary significantly across different administrative regions and household structures, emphasizing the need for localized proxy thresholds rather than a single nationwide blanket metric.
* **Survey-Weighted Reliability**: Utilizing survey-weighted analysis ensured that findings accurately reflect broader national demographic trends.
